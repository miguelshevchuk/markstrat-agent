# Análisis de Segmentos

## Cómo leer los estudios de segmentos

### Semantic Scales (Estudio 4)
- Muestra cómo perciben los consumidores cada marca en cada atributo
- Una brecha entre percepción y realidad → problema de comunicación o specs
- Una brecha entre lo que el segmento desea y lo que tu marca ofrece → oportunidad de I+D

### Multidimensional Scaling (Estudio 5)
- Mapa perceptual: dónde está cada marca en el espacio de preferencias
- Los puntos "ideales" de cada segmento = dónde deberías posicionarte
- Si estás lejos del ideal → ajustar specs o comunicación

### Conjoint Analysis (Estudio 11)
- Te dice el peso relativo de cada atributo para cada segmento
- Ejemplo: para Profesionales, el Processing Power puede valer 40% de la decisión
- Usar para diseñar specs de I+D con máximo impacto

## Framework de análisis por segmento

Para cada segmento objetivo, responder:
1. **¿Qué atributos valoran más?** (Conjoint)
2. **¿Cómo perciben nuestras marcas?** (Semantic Scales)
3. **¿Dónde estamos en el mapa perceptual vs. el ideal?** (MDS)
4. **¿Cuánto compran y por qué canal?** (Consumer Panel)
